# C1.7 reviewer staffing

The hosted baseline had zero Community Needs review grants and zero pilot enrollments. Existing C1.2 authority has community, lane, expiry and revocation fields. It has no pending appointment record. A vacancy or proposed alternate stays in the staffing plan until an authorized scoped grant actually exists. The workspace displays eligible, expired, revoked and recertification states and current assignment and challenge counts.

| Responsibility | Minimum proposed Ouest coverage | Alternate and escalation |
| --- | --- | --- |
| Intake triage | One eligible triager assigned in Ouest | One separately qualified backup. The coordinator checks the roster before handing off |
| Independent evidence | One of four distinct eligible reviewers | A conflict-free reserve takes over through the native assignment workflow |
| Publication | A different eligible reviewer | Verify exact reviewed evidence, snapshot and consent before accepting |
| Project association | A different eligible reviewer | Verify the publication, project revision and author consent |
| Challenge | A different eligible reviewer | Route away from any original decision maker and follow the existing 14-day challenge rules |
| Support and incident command | Coordinator and support alternate | Only the approved private channel and minimal identifiers. Raise authorization or evidence concerns to incident command |

Four reviewer responsibilities are the proposed operating roster using the existing independent review lane. This does not appoint anyone or add a new role. Verify recent MFA and the actor-bound workspace for each shift. Verify native authority, Ouest scope, grant expiry, active eligibility, non-participation and available hours before assigning. Document recusal by case reference in the existing workflow and log the replacement. Never let the Founder act as an independent reviewer. Escalate vacancy, backlog or expiry to the coordinator and pause when minimum independent coverage cannot be maintained.

Future department rosters follow this same template independently. A national coordinator reviews staffing capacity, availability across departments, expiration reminders, challenge deadlines, and support language coverage. A reserve can serve more than one department only after separate scoped authorization, workload review, and conflict screening. Local coordinators see only their authorized scope. Review roster validity before each department’s activation and at handoff, and renew explicitly before expiry. No real appointments were made for C1.7.
