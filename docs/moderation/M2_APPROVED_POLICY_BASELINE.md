# Approved M2 enforcement direction

These requirements guide future phases. M2.1 adds the read-only Moderation Center and retains current enforcement semantics.

| Decision | Approved direction for future implementation |
| --- | --- |
| Indefinite and high-impact actions | Founder-only indefinite bans and designated high-impact restrictions. |
| Administrator duration | Temporary restrictions of up to 90 days. |
| Moderator duration | Explicit delegation for feature restrictions of up to 7 days. |
| Expiration | Trusted database time determines whether a temporary restriction is effective. |
| Existing sanctions and evidence | Preserve historical evidence and existing sanctions. Keep attribution and avoid inferring end dates. |
| Independent review | Preserve conflict protections and independent appeal eligibility and assignment. Use a proposed 14-day baseline for eligible new enforcement appeals while preserving existing domain-specific deadlines. |
| Restricted account access | Provide a narrow, authorized path for account security, notices and eligible appeals. |
| User-authored content | Supervisory decisions may change visibility through approved actions. Moderators cannot silently rewrite member-authored statements. |

Protected governance, scope, access and retention decisions from M1 still apply. The approval covers the listed direction. Details outside it remain owner decisions before implementation. [M1 owner decisions](M1_OWNER_DECISIONS.md) · [M2.1 implementation](M2_1_IMPLEMENTATION_REPORT.md)
