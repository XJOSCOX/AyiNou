# I1 existing and missing capabilities

| Gap | Existing foundation | Next capability | Priority |
| --- | --- | --- | --- |
| Reviewed local needs | Department and group discussion, proposal problem statement | Scoped need intake, evidence references, duplicate triage, attribution and review history | C1 |
| Needs to projects | Existing community association and proposal lifecycle | Trace an approved proposal to a reviewed need with compatible visibility and explicit linking authority | C1 candidate after intake |
| Trusted information | Scoped badges, moderation reports, project evidence review | Evidence-based public claims workflow with provenance and disposition | Start with need evidence in C1. Expand public-claim coverage after review capacity exists. |
| Independent outcomes | Project reports, milestones, evidence and outcomes | Cross-scope validation with conflict checks, versioned review and appropriately public assurance | C2 |
| Measurable results | Homepage community counts and project-level measures | Privacy-reviewed community aggregation with traceability and sound metric definitions | C2 after validated data |
| Volunteer skills and matching | Project opportunities, applications and assignments | Opt-in skills and availability with matching to real project tasks | C3 |
| Trusted radio and media | Feed publishing and images | Source registry, editorial responsibility, rights and verified corrections before distribution | Later |
| Opportunities and mentorship | Groups, events and projects | Dedicated opportunity and matching workflows with safeguarding where appropriate | Later |
| Contributions and financial transparency | Work contribution records | Legal and accounting ownership, payment reconciliation, disclosures and verified controls before accepting funds | Later |
| Mobile and low bandwidth | Responsive site and bounded media | Measure low-bandwidth member journeys, then assess web offline behavior and native clients | Measurement early. Native expansion later. |

The register identifies eight missing entries across these pathways and four partial entries, including independent outcomes, multilingual feed, mobile web and observability.
