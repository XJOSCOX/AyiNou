# C3 final end-to-end tests

The isolated rehearsal connects Founder decisions to the owner profile, separate consent, native opportunity and structured publication, recommendations, scoped discovery, contact consent, invitation and in-app notice, native application, offer, confirmation, and task participation. It tests expiry, permission loss, deterministic pause invalidation, retry and concurrent handling alongside earlier C3 regression suites.

The complete flow uses one individual project in Ouest. Earlier C3 regressions cover other departments and individual, community and organization ownership. Those checks do not constitute a complete lifecycle in each department. Disposable accounts and records are used for enabled tests. Connected Test02 and J0SC0X browser checks inspect closed states and protected administration without creating hosted volunteer records.

The fresh disposable run passed one integrated activation/lifecycle/recovery test and three matching tests, including the 100,000-profile benchmark and the exhaustive reference comparison. A six-request mixed workload crossed two local API instances. The release verification and connected account observations are recorded in the [implementation audit](C3_FINAL_IMPLEMENTATION_AUDIT.md).
