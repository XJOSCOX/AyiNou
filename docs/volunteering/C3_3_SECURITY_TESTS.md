# C3.3 Security tests

The disposable authorization suite verifies closed gates, native authority, version-bound settings and reachability, separate consents, account and profile visibility, scoped organizer disclosure, blocks in both directions, expiry, catalog retirement, protected revisions and interactions with existing applications. Public and authenticated roles cannot execute the service RPC or read private records. The Fastify route verifies the session and rejects unknown search or configuration controls. Opaque continuation binds to the actor, session, route, project and opportunity, revision, filters and expiry.

The local browser checks use Test02 and J0SC0X without editing hosted profiles or projects. The seeded browser and performance tests are confined to disposable Supabase. Query and response measurements are recorded in the performance report.
