# C3.1 Skills catalog

The initial catalog has version-one definitions in fifteen categories. Each definition has a stable code, labels in English, Haitian Creole, French and Spanish, search aliases, lifecycle state and optional descriptions in all four languages. Current display definitions live in the catalog. The migration is the version-one baseline. Subsequent changes record their complete snapshots with version, actor, reason and workspace in the private configuration history.

Search uses stable codes, localized names and aliases. The database reserves normalized names and aliases, including earlier terms, to prevent different skills from claiming the same term. Different translations can share a term when they refer to the same skill. The catalog is capped at 500 definitions. A skill can be drafted, listed for selection in a future eligible intake, or retired. Retiring a skill or disabling its category excludes new selections and preserves existing selections. No labels or aliases imply certification. No member interest is automatically converted to a skill.
