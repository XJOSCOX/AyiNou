# C3 final privacy review

| Record | Disposable export and lifecycle decision |
| --- | --- |
| Profile, skills, experience, availability | Own profile fields and coded selections in an existing owner-authorized synthetic export. Review erasure and holds before live use. |
| Matching, discovery, future display and contact consent | Own current choices and current pause. Display preference does not publish selected skills. |
| Dismissals | Bounded own opportunity/version history. |
| Invitation message and lifecycle | Own minimized status and dates only. Private messages, counterpart data, event receipts and native application provenance stay in their restricted ledgers. |
| Notifications | Authorized invitation ID and state in the existing in-app inbox. No message copy or profile input. |
| Founder decisions and configuration | Restricted actors, reasons, versions, scopes and receipts. Review administrative retention independently. |
| Native application, report and team data | Existing native retention and hold behavior. No C3 purge. |

When a disposable C3 record affects a lifecycle plan, the existing plan marks a protected dependency for review. The synthetic export redacts third-party fields. Real export and erasure remain closed, and final retention periods remain undecided. Before release, approve lifecycle dispositions, provider-backed recovery and a monitored hold reconciliation process. Existing native moderation and reporting rights remain available.
