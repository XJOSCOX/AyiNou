# AyiNou Android roadmap

| Phase | Scope |
| --- | --- |
| A0 | Backend deployment and remote API readiness |
| A1 | Native Android foundation |
| A2 | Native authentication and required onboarding for disposable local testing. Remote access depends on A0. |
| A3 | Dashboard and member profiles |
| A4 | Feed, posts, media, comments and reactions |
| A5 | Discovery, following and notifications |
| A6 | Communities and groups |
| A7 | Organizations and institutional profiles |
| A8 | Events and Projects |
| A9 | Community Needs and Impact |
| A10 | Volunteering and skills matching |
| A11 | Opportunities and mentorship |
| A12 | Account settings, privacy and safety |
| A13 | Offline capabilities, performance and push notifications |
| A14 | Final integration, security and Android release preparation |

A3 and later phases require separate authorization. Render confirmed Free instance ingress. A0 remains open pending manual deployment and authenticated verification. A paid instance requires a separate ingress and proxy security review. C5 Trusted Haitian Media and Information and C6 Donor Connections remain deferred.
