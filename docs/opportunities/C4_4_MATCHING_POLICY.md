# C4.4 mentorship matching

A match evaluates opposite role profiles. A member can participate in both roles. Recommendations require the viewer’s role-specific recommendation consent and a candidate’s independent discovery consent. Discovery also requires the viewer’s discovery consent. Neither grants request permission. Sending requires both discovery and request consent and a short-lived selection bound to the viewer’s role and both profile revisions.

The first pass joins an indexed role/topic lookup using only opted-in profiles. Each shared topic yields at most 129 IDs after the cursor. A page checks at most 128 candidates, orders deterministically by opaque profile ID and returns at most 12 projections. The cursor authenticates the role, profile revision, lane, filters, boundary and expiry. Traversal stops after eight pages. The result is a bounded search with stable ordering, with no global ranking or bulk export. Only the native privacy-permitted name, username, role, scoped compatibility explanations and selector leave the database.

Shared topics, language, mode and geographic compatibility determine whether a request can be offered. Optional Founder preparation can include skills and proficiency, scheduling fit and self-reported experience. Shared skills and relative proficiency indicate whether someone can support the other participant’s declared goals. Freeform learning objectives and professional summaries are neither compared as keywords nor disclosed to candidates. Missing skill or experience information has its own explanation. Compatibility describes fit under stated preferences. It confers no credential or quality guarantee.

Haiti department preferences use the ten existing identifiers. Haitian nationwide, explicitly selected countries and worldwide remote participation use the C4.3 geography vocabulary. Languages and C3 skills use existing catalog identifiers. Nationality, payment, donation, follower counts, account rank and professional reputation are absent from selection and compatibility.
