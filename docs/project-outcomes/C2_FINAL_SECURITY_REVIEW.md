# C2 final security review

## Access matrix

| Role | Authorized boundary |
| --- | --- |
| Guest | Existing native public projects and the approved C2.3 or Impact projection, when enabled. Private evidence, administration and command RPCs are denied. |
| Ordinary member, verified member, Founder Verified member | Existing member routes. Identity satisfies native identity checks. Protected review or administrative access requires separate grants. |
| Project owner and organization operator | Source inspection, submission and relevant consent for their exact native project and eligible source. No independent decision authority. |
| Manager, contributor, volunteer | Native Project Work permissions. C2 requester and consent actions still require the native operator and exact record conditions. |
| Moderator and administrator | Native moderation and oversight allowed by their grants. Neither designation conveys independent C2 decision authority. |
| Founder | Assignments and settings through current MFA-bound administration. Independent findings, publications and report decisions retain separate eligibility checks. |
| Outcome, challenge, publication and mapping reviewer | Purpose and department grant as applicable, scoped cases, current evidence and assignment, independent decision checks and current original-session workspace. |
| Assignment coordinator | Authorized case assignment within the department, with no grant appointment or decision authority by coordination alone. |
| Impact governance reviewer | Separately appointed, expiring grant with independent report approval and exact snapshot binding. |

## Boundaries and tests

The audit read service-only command ACLs and private table RLS, exact source and manifest binding, media data handling, no-store response headers, ID and version checks, and receipt/version logic. Tests cover ordinary denied reads, unrelated actors and departments, stale workspaces and grants, independent assignment, concurrent reviewer operations, consent and evidence revocation, and preserved private history. Authorization assertions use supported operations and disposable identities.

C25-01 adds permanent withholding on relationship and consented association dependencies. Existing account, authentication, project and publication checks remain in force. Direct media is checked again under the specific case and evidence revision before decoding data. Direct table privileges remain closed to application roles.

## Closed-gate administrative preparation

Recognized Founders can prepare Impact display preferences, staffing slots and draft measurements under recent MFA and the original administrator workspace. These commands have no activation field and grant no evidence, publication, reporting or reviewer authority. [C2.6 configuration security](C2_6_CONFIGURATION_ACTIVATION_SEPARATION.md)

## Statistical security

Reports use disjoint calendar-year sector cohorts, exact source identity and independent mapping, distinct owner thresholds, suppression of small contributing partitions, and conservative national suppression. Fixed dimensions and permanent report withdrawal limit comparison with later versions. See [privacy review](C2_FINAL_PRIVACY_REVIEW.md).
