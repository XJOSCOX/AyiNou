# C2.4 measurement catalog

Each stable identifier has versioned localized names, descriptions, methods and units in Haitian Creole, French, English and Spanish. A definition records its sector, machine unit, output or outcome classification, canonical methodology code, aggregation flag, privacy classification, calendar-year requirement, delivery-reference rule and lifecycle state.

| Initial definition | Sector and unit | Reviewed methodology design | Installed state |
| --- | --- | --- | --- |
| `school_desks` | Education, desks | Accept newly delivered desks against a signed delivery inventory. Count each accepted desk once for the calendar year. Canonical code `SIGNED_DESK_HANDOVER_V1`. | Draft |
| `tree_planting` | Environment, trees | Count newly planted trees once from the accepted planting log for the calendar year. Canonical code `ACCEPTED_PLANTING_LOG_V1`. | Draft |

The shipped drafts are conservative, non-sensitive output designs. Installation creates neither an approval nor a report. A current independently appointed governance reviewer approves the exact catalog version. The Founder can prepare a revised definition, retire it, and enable eligible reporting categories. A reviewed definition stays fixed. Activation of a replacement retires the previous active version. Earlier versions and decisions retain their audit history.

The sector vocabulary includes education, healthcare, agriculture, environment, infrastructure, economic development and community development. Healthcare appears in coverage reporting. The initial numerical policy excludes healthcare, restricted measurements, person-level quantities and outcome quantities with unresolved deduplication. The protected unit list includes desks, trees, items, classrooms, sessions, kilograms, hectares, meters and wells. Approval still requires the methodology to define a specific, non-sensitive output.

A numeric mapping requires the exact independently recorded method code, the same unit, calendar-year boundaries and output classification. Decimal quantities and unit conversions stay outside this policy. The reviewer assesses the delivery reference, the original finding and the catalog method. A changed definition or observation requires a new mapping decision. Existing custom metrics stay available through Project Work.
