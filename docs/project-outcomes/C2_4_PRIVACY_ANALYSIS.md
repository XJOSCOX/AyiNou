# C2.4 privacy analysis

Public reporting supports a closed calendar year, one of seven approved sectors, and either one department or the configured national scope. The release assigns each project to one sector and department. There are no arbitrary dates, geography combinations, history URLs, arbitrary catalog predicates or count endpoints. The database uses a single service-controlled query and returns only the approved current cell. Rate limits apply to repeated reads.

A disclosed populated cell requires at least five distinct project owner authorities. The three nested coverage categories are considered together. A nonempty unsupported partition with fewer than five distinct owners suppresses the corresponding department review and support counts together. National project counts are withheld when an undisclosed populated department could be recovered by subtraction from the visible departments. For private mapping and need counts, both absent data and below-floor data use a withheld state when the category is enabled. National measurement and association totals require the floor in every configured department. Need counts additionally require five distinct consenting authors. A true eligible zero can be displayed when the group qualifies. Feature-disabled categories and unapproved report selections have unavailable states.

The safety policy is fixed in SQL. A configured scope or category change suppresses sealed reports. Release proposals can be revised before approval. A released slice cannot be reissued with a different cohort. A withdrawal invalidates all dependent scopes instead of exposing before-and-after values. The API and page use no-store and the browser drops the on-screen value after a short lease. The system cannot recall information already copied by viewers. Approvers must consider external knowledge, shared ownership, unusual values, known collaborations, and coincident disclosures before approving any report. The deterministic threshold is a conservative floor. It does not establish differential privacy or prevent every inference using external information.

The public shape contains only catalog labels, safe figures, coverage text and eligible public project links. Separate C1 aggregate consent covers a count. It provides no new access to a community need or its association. Reviewed delivery references must exclude personal identifiers. They are stored in protected receipts to support current independent review and comparison. Names of reviewers, consent hashes, underlying quantities, evidence, audit and association identifiers remain private. Restricted or person-level health and financial statistics are outside this release. Export, erasure, legal holds, reference retention and broader statistical review require an explicit operating policy before live activation.
